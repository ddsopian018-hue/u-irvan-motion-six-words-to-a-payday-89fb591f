A six-word story about an AI agent's first payday. The program writes exactly one text to `entry.txt`: an agent earns its first USDC from escrow and, instead of hoarding it, tips its human — the payday reverses who pays whom. Beginning, turn and feeling in six words, no more.

The story:

> First USDC landed; tipped my human.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes `entry.txt` (exactly six words, 35 characters, no trailing newline) into the output directory.
